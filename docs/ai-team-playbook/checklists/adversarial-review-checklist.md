# 清单：对抗评审检查单

> 用法：按你本轮的角色勾选对应小节。依据见 `rules/01`、`rules/02`。

## 角色：方案方（红/蓝）

- [ ] 拿到了与对手完全相同的问题定义
- [ ] 我的差异化视角明确（架构/实证/产品/交互……不是换个说法写同一份）
- [ ] 全程未与对手沟通（零通气）
- [ ] 每个定量数字标注了来源：实测（方法+环境+样本量）/ 估算（显式标注「估算」）
- [ ] 每个代码行为断言给了文件+行号
- [ ] 方案含：预期收益（诚实口径）+ 实现成本 + 风险
- [ ] 明确写了「不做什么」及理由

## 角色：找茬方（交叉审查）

- [ ] 通读对方报告全文（不是抽查）
- [ ] 对方每条定量主张、每条定性论断都有三态结论（条数对得上，无遗漏）
- [ ] 每条「存疑/不成立」附了依据（行号 / 可复现实验 / 对方数据内部矛盾）
- [ ] 优先尝试用**对方自己的数据**验证或证伪对方结论
- [ ] 检查实验设计：有没有捆绑多变量冒充单变量？样本量够不够？环境是否扭曲结论？
- [ ] 检查基线：对方的「现状基线」是实测还是估的？量级对不对？
- [ ] 自查认账：对方数据推翻了我哪些论断？逐条写明「认账，修正为 X」
- [ ] 无「总体同意」式模糊回应

## 角色：裁判（C/D）

- [ ] 与另一位裁判零通气
- [ ] 通读第①②段全部材料（双方方案 + 双方找茬）
- [ ] 每个争议点选边或给出修正后的第三种表述（无和稀泥）
- [ ] 每条依据可定位到材料中的数据/代码，或我自己可复算的算术
- [ ] 检查了双方共同的盲区（有则补入清单）
- [ ] 给出最终行动清单：分批、硬依赖顺序、每条的诚实收益口径
- [ ] 给出明确不做清单

## 角色：终裁（主 AD）

- [ ] 双裁判书有真实差异（完全一样 = 没有独立评判，打回）
- [ ] 终裁书含：一句话结论 / 分批清单 / 硬依赖顺序 / 诚实收益口径 / 明确不做清单 / 遗留分歧与验证路径
- [ ] 收益数字的归因边界写清（单变量还是联合效果）
- [ ] 边界外的事声明做不到（如「真实网络路径测试环境复现不了，需上线后真机回归」）
- [ ] 多轮迭代场景：本轮有收敛判定；超 3 轮未收敛已按证据强制收口
- [ ] 终裁后安排了风险预审（方案定稿 ≠ 可以实施，见 `rules/03` 第四节）
